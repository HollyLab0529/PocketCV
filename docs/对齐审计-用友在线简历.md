# 对齐审计 · 用友招聘在线简历（2026-11-18 实测）

来源：career.yonyou.com 用友校招「产品经理（B端）-27届」投递在线简历（resumeOperation.html，recruitType=1），
登录态下逐区抓取 13 个分区、283 个表单项与全部下拉枚举。

## 用友表单结构（13 区）

| 分区 | 必填 | 字段（控件） |

| 教育经历 | ✔ | 开始时间、结束时间、学校(下拉)、学历(下拉)、专业、是否统招(下拉)、是否挂科(单选) |
| 英语能力 | ✔ | 英语证书名称(下拉：四级/六级/专四/专八)、成绩(下拉：未通过/通过/优秀)、获得时间 |

## 消缺清单（对照 PocketCV 现有结构）

### A. 缺失，建议新增
1. **家庭关系模块**（用友必填区）：关系/姓名/工作单位/职位，多条——现有「紧急联系人」覆盖不了
2. **独立证书模块**：证书名称/获得时间/说明——现在证书埋在技能清单文本里，网申要逐条填
3. **技能补「使用时间」**：用友技能三件套=技能类别+使用时间+掌握程度，缺中间项（如「2年」）
4. **通信地址**（基本信息）：现居住城市≠详细地址
5. **婚姻状况**（基本信息）：未婚/已婚/保密
6. **布尔小字段**：是否全日制、是否统招、是否挂科、是否有海外留学经历
7. **工作经历模块**：企业名称/职位名称/所在部门/工作描述/起止——与实习经历同构，补「所在部门」

### B. 结构要拆（遵循「对应独立输入框必须拆字段」原则）
8. **教育经历时间拆「开始时间/结束时间」**：现在是合并「在校时间」文本，网申都分开填；且教育经历要支持多条（第一学历/最高学历）
9. **实习经历补「开始时间/结束时间」**：现在也是合并「起止时间」
10. **项目经历补「项目职责」独立字段**：用友是「项目描述/项目职责」两个 textarea，与既定两段式约定一致

### C. 同义词/匹配补齐
11. 「技能名称 ↔ 技能类别」互相映射；「使用时间」「毕业时间」「所在部门」「婚姻状况」「通信地址」「关系」入同义词表
12. 「籍贯」已由「户口所在地」同义词覆盖 ✅；「移动电话→手机」「企业名称→单位名称」已覆盖 ✅

### D. 明确不做（保持「宁可不填也不填错」）
- 招聘信息获取来源 / 是否接受调剂 / 是否内推：纯站方问卷题，站站不同，手动填
- 照片 / 简历附件上传：文件类自动上传风险高
- 下拉点选（学历/掌握程度等枚举）：已有自定义下拉机制，待真实页实测

## 落地注意
- 任何字段结构变更必须附带一次性迁移（旧数据补新字段），regroupSkills 模式可参考
- 用友技能的「技能类别」值多为「Python / SQL / Axure」这类技能名，与现有技能卡片数据可直接复用
